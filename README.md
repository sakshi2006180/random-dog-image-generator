🐶 Random Dog Image Generator

A simple JavaScript project that fetches and displays a random dog image using the Dog API and Axios.

🚀 Features

* Get a random dog image
* Fetch data from a real API
* Uses Axios and Async/Await
* Simple DOM manipulation
* Basic error handling

🛠️ Technologies

* HTML
* JavaScript
* Axios
* Dog API

🔗 API

`https://dog.ceo/api/breeds/image/random`
